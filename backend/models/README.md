# Models Directory

This directory is ready for your Mongoose models.

As you build out the backend step-by-step, you can create your schemas and models here:

- `User.ts` (Consumers & Business Owners)
- `Category.ts` (Craft categories taxonomy)
- `Work.ts` (Artisanal listings & services)
- `Booking.ts` (Client custom orders & bookings)

### Reference Data
You can inspect `backend/data/initialData.ts` to see sample data and TypeScript interfaces for reference.
